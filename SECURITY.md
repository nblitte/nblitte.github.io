# Politique de sécurité

Ce dépôt contient un site statique (Astro) sans backend, sans base de données et sans collecte de données personnelles.

## Signaler un problème

Si tu identifies un problème de sécurité (dépendance vulnérable, contenu injecté, mauvaise configuration du déploiement) :

1. N'ouvre pas d'issue publique avec le détail.
2. Contacte directement l'auteure via le profil GitHub ([nblitte](https://github.com/nblitte)) ou LinkedIn.
3. Décris le problème et les étapes de reproduction.

## Mesures en place

- Dépendances surveillées par Dependabot (npm et GitHub Actions).
- Déploiement uniquement via GitHub Actions, avec des permissions minimales.
- Aucun secret dans le dépôt.
